# Deep Learning Datasets

40 Kaggle datasets for deep learning projects, downloaded and committed here so you can clone once
and start training. Vision, NLP, audio and 1D signal tasks.

Every dataset is under 100 MB to download, and **no individual file reaches 100 MB**, so nothing here hits
GitHub's file size limit. The largest single file in the repo is 83.3 MB.

## What's here

Each folder is one dataset, named after its Kaggle slug. `catalog/datasets.json` holds the machine readable
index (slug, task, size, license, source URL) and `catalog/deep_learning.md` has the long form notes.

## Task coverage

Image classification, non-Latin handwriting (Chinese, Arabic), gesture and sign language recognition,
medical imaging (brain MRI, chest X-ray, dental, fractures), object detection in YOLO and VOC formats,
semantic segmentation, OCR with CTC, remote sensing, sentiment analysis, multi-label text, question
answering, machine translation, named entity recognition, text generation, speech and audio
classification, and 1D physiological signals.


## Re-downloading from source

The datasets are committed, so cloning is enough. To refresh them from Kaggle instead:

```bash
pip install -r scripts/requirements.txt
kaggle auth login
python scripts/download_datasets.py --all
```

The downloader enforces the size rule on every run: it skips anything at or over 100 MB, and after
unzipping it walks the extracted files and removes any dataset that hides an oversized file inside a small
archive. Pass `--cap 0` to turn that off.
